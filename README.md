# CrisisAssist – Disaster Recovery & Crisis Management System

## Project Overview

**CrisisAssist** is a web-based Disaster Recovery and Crisis Management System developed as a **Database Management Systems (DBMS) Laboratory course project during the 2nd Year, 2nd Semester** at **Bangladesh University of Professionals (BUP)**.

The project aims to provide a centralized platform for managing disaster response activities such as emergency alerts, shelter information, volunteer coordination, rescue team management, donations, and organization administration.

> ⚠️ **Note:** The original source code files were unfortunately lost. This repository is created to showcase the project UI, database design, and project documentation.

---

## Features

* Role-based authentication (Admin, Organization, Volunteer, User, Affected People)
* Emergency Alerts & Crisis Updates
* Global and Local Disaster News
* Shelter Information & Availability
* Donation Management System
* Rescue Team Management
* Organization Dashboard
* Admin Dashboard with database management
* CRUD operations for data records
* Search and filtering functionality
* Responsive user interface

## Database Design

The database was designed following **Third Normal Form (3NF)** to ensure:

* Reduced data redundancy
* Improved data integrity
* Better relational structure
* Efficient data management

### Included Design Artifacts

* Entity Relationship (ER) Diagram

## Challenges Faced

During development we faced several technical challenges, including:

* Designing a normalized MySQL database
* Managing relationships between multiple tables
* Integrating Flask with MySQL
* Implementing role-based access control
* Handling CRUD operations correctly
* Maintaining synchronization between database and web interface
* Time constraints for implementing advanced features

These challenges significantly improved our understanding of DBMS concepts and backend development.

## Limitations

The current project has some limitations:

* No real-time disaster API integration
* No live location tracking
* No notification or SMS system
* Limited analytics and reporting features
* No interactive GIS map integration
* Basic security implementation
* Some planned advanced features were not completed
